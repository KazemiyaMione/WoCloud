# WoCloud —— 联通云盘第三方桌面客户端

用 C# / .NET 8 + WinUI 3 写的联通云盘桌面客户端，覆盖文件浏览、上传下载、分享、回收站、私密空间、家庭云与会员信息。

> ⚠️ **本项目非官方产物**，与联通公司无任何关联。仅供个人学习与自用，请勿用于商业用途、批量抓取或任何违反服务条款的场景。使用产生的后果由使用者自行承担。
>
> 仓库内**不包含**底层协议细节（请求结构、加解密参数、接口参数表），这些内容不随源码分发。

## 功能

| 页面 | 能力 |
|---|---|
| 文件（主界面） | 分类 tab、空间切换（个人云/家庭云）、面包屑、搜索、双击预览、右键 预览/下载/分享/移动/复制/移入私密空间/重命名/删除、上传、加载更多、缩略图 |
| 文件预览（文件页与私密空间页共用） | 图片（原图 + 缩放 20%~800% + 旋转 + 适应窗口）、视频/音频、文本（≤1MB）、其他格式信息面板 + 「用系统应用打开」；←/→ 切换文件、Esc 关闭、窄窗口自动精简工具栏 |
| 右上角用户区 | 圆形头像、昵称、会员摘要，点击进入会员空间 |
| 传输 | 与文件页共享同一队列、进度/已传大小/时间、失败原因原样展示、清理已完成 |
| 设置 | 外观主题（跟随系统/浅色/深色，即时生效）、默认下载目录、同时下载数(1~5)、断点续传、传输后自动刷新、上传分片(8/16/32MB)、账号信息、**个人资料（昵称/性别/生日/头像上传）**、**修改密码（短信验证码，无需旧密码）**、退出登录、清除本地缓存 |
| 关于与合规 | 版本信息、GitHub / 问题反馈 / 更新日志 / 许可证入口、第三方组件清单、首次登录强制阅读 10 秒的免责声明（不同意直接退出，同意版本号本地持久化） |
| 分享管理 | 我的分享（提取码/有效期/短链）、复制、取消/删除、打开他人分享并下载 |
| 飞传接收站 | 列表、接收（转存根目录）、删除 |
| 回收站 | 列表、还原、永久删除、清空 |
| 私密空间 | 密码解锁、浏览、移出到个人云、下载、锁定 |
| 会员空间 | 头像/昵称、会员等级、空间进度条（已用/剩余/占比）、有效期、自动续费、会员权益（单文件上限/回收站天数/家庭人数/快传次数）、家庭云群组、每日打卡（本地记录） |
| 调试面板 | 手工发起原始请求、查看原始返回，便于排障 |

## 项目结构

```
WoCloud.slnx
├── src/
│   ├── WoCloud.Client/        # 协议类库（net8.0，零 UI 依赖）
│   │   ├── Core/              # 请求封装、会话状态、常量、统一异常
│   │   ├── Auth/              # 短信登录 / 密码登录 / 扫码登录 / Token 直通
│   │   ├── Files/             # 列表、目录、搜索、增删改移、下载直链、回收站
│   │   ├── Transfer/          # 分片上传、流式下载（.part 断点续传）、飞传
│   │   ├── Share/             # 分享创建/取消/转存/查看他人分享
│   │   ├── Space/             # 私密空间
│   │   ├── Member/            # 会员摘要与权益
│   │   └── Models/            # DTO
│   ├── WoCloud.App/           # WinUI 3 客户端（Mica + Fluent）
│   │   ├── Views/             # Login · FileList · Transfer · Share · FlyPass
│   │   │                      # Recycle · PrivateSpace · Member · Settings · Lab
│   │   ├── ViewModels/        # CommunityToolkit.Mvvm
│   │   ├── Controls/          # 文件预览浮层
│   │   └── Services/          # 设置、DI、主题
│   └── WoCloud.ConsoleTest/   # 控制台冒烟（不依赖 UI 即可验证全流程）
└── tests/WoCloud.Client.Tests/ # 协议层单测（加解密、会话、分片等）
```

## 快速开始

环境：Windows 10 1809+ / Windows 11、[.NET 8 SDK](https://dotnet.microsoft.com/download)、Visual Studio 2022（含「Windows 应用开发」工作负载）或 VS Code + C# Dev Kit。

```powershell
# 1. 还原 & 单测（不需要登录）
dotnet test tests/WoCloud.Client.Tests

# 2. 控制台冒烟（三选一）
dotnet run --project src/WoCloud.ConsoleTest -- qr                 # 扫码登录
dotnet run --project src/WoCloud.ConsoleTest -- sms 13800000000    # 短信登录
dotnet run --project src/WoCloud.ConsoleTest -- <粘贴的token>      # Token 直通

# 3. 桌面客户端
dotnet build src/WoCloud.App -p:Platform=x64
dotnet run  --project src/WoCloud.App -p:Platform=x64
```

登录态保存在 `%LOCALAPPDATA%\WoCloud\session.json`，下次启动自动恢复；在「设置 → 退出登录」会一并清理。

## 已知限制

- 上传已打通（文件与整个文件夹），**秒传/断点续传未做**
- 私密空间**首次设置密码**需短信验证码流程，未在客户端实现，请先在官方网页设置后再解锁
- 家庭云只做了浏览与增删改，未做成员管理/邀请
- 移动/复制目前只能选根目录与一级目录，未做完整目录树选择器
- 文件列表按页加载（每页 100，「加载更多」翻页），未做无限滚动
- 缩略图直接绑定服务端返回地址，若该地址需要额外鉴权则显示为类型图标
- 会员信息接口对部分登录方式返回 500，此时会员页显示空数据，不影响其他功能
