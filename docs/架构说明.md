# 架构说明

> 本文只描述工程结构与实现约定，**不包含**服务端协议细节（请求结构、加解密参数、接口参数表）。
> 需要那部分内容请参阅作者本地的内部文档，不随源码分发。

## 1. 分层

```
┌─────────────────────────────────────────────┐
│ WoCloud.App（WinUI 3）                       │
│  Views（XAML）  ←x:Bind→  ViewModels         │
│  Controls（预览浮层）  Services（DI/设置/主题）│
└───────────────┬─────────────────────────────┘
                │ 只依赖类库，无反向依赖
┌───────────────▼─────────────────────────────┐
│ WoCloud.Client（net8.0，零 UI 依赖）          │
│  Core（请求封装、会话、常量、异常）            │
│  Auth / Files / Transfer / Share / Space /   │
│  Member / Misc + Models                      │
└─────────────────────────────────────────────┘
```

类库不引用任何 UI 程序集，因此可以被 `WoCloud.ConsoleTest` 直接调用，也可以被单元测试覆盖。

## 2. 应用层约定

- **DI**：`Services/AppServices.cs` 统一注册单例（客户端类库、设置、传输队列、各 VM），页面通过构造函数拿到 VM。
- **MVVM**：VM 继承 `ObservableObject`，属性用 `[ObservableProperty]`，命令用 `[RelayCommand]`。
- **绑定**：XAML 统一用 `x:Bind`（编译期检查）；需要随属性变化的派生值，在 `NotifyDerived()` 里显式 `OnPropertyChanged`。
- **导航**：`MainWindow.Navigate<TPage>()` 负责切页面、维护导航选中项；登录页会隐藏导航栏（`_suppressNav` 屏蔽选择事件，避免初始选中项把登录页顶掉）。
- **主题**：`App.ApplyTheme(int)` 对窗口根元素设 `RequestedTheme`（运行时可改），并同步 DWM 沉浸式深色属性与标题栏按钮颜色。

## 4. 关键实现点

- **文件预览**：`Controls/FilePreviewOverlay` 同时被文件页与私密空间页复用；图片支持缩放/旋转/适应窗口，文本按大小截断，其余格式交由系统应用打开。
- **传输队列**：`TransferQueue` 是上传/下载任务的唯一来源，文件页与传输页共享同一实例，所以两处看到的是同一批任务。
- **断点续传**：下载写 `.part` 临时文件，完成后重命名；是否启用由设置项控制。
- **设置持久化**：`AppSettings` 每个 `[ObservableProperty]` 变更即写 `settings.json`（`%LOCALAPPDATA%\WoCloud`），无需显式保存。
- **图标系统**：文件/目录图标按扩展名在客户端分类（不依赖服务端文件类型字段），文档类用扩展名角标，缩略图加载失败自动回退到类型图标。

## 5. 本地文件

| 位置 | 内容 |
|---|---|
| `%LOCALAPPDATA%\WoCloud\session.json` | 登录态（含 accessToken），退出登录会删除 |
| `%LOCALAPPDATA%\WoCloud\settings.json` | 下载目录、并发、主题、打卡记录等 |

两者的写入路径依次回退：`LocalAppData` → `Roaming` → `Temp` → 程序目录，方便做成便携版。

## 6. 构建与测试

```powershell
dotnet test  tests/WoCloud.Client.Tests          # 协议层单测，无需登录
dotnet build src/WoCloud.App -p:Platform=x64     # 桌面客户端
```

- 客户端目标框架 `net8.0-windows10.0.19041.0`，依赖 Windows App SDK 1.6。
- exe 图标由 `csproj` 的 `ApplicationIcon` 写入（需「重新生成」）；窗口/任务栏图标由运行时 `AppWindow.SetIcon` 设置。
- 单测聚焦加解密、会话状态、分片计算等纯逻辑，不发真实网络请求。

## 7. 排障入口

| 现象 | 先看这里 |
|---|---|
| 一启动就进主页、看不到登录页 | `MainWindow.xaml.cs` 的 `_suppressNav` 与导航选中逻辑 |
| 接口报错但界面无提示 | 对应页面的 `StatusText` / InfoBar 绑定是否遗漏 |
| 切主题后背景不跟随 | `App.ApplyTheme` 中 DWM 沉浸式深色属性是否设置成功 |
| 会员信息空白 | 该接口对部分登录方式返回 500，属服务端会话差异 |
| 上传卡住 | 分片大小与并发设置；`TransferQueue` 中的失败原因 |
